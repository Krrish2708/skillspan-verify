
# VerifyHire – AI-Powered Resume Verification Platform

VerifyHire is a full-stack SaaS platform that goes beyond traditional ATS scoring by verifying the credibility of candidate resumes using AI. It cross-validates resume claims against GitHub repositories, project links, certifications, and job descriptions to provide recruiters with a more reliable hiring decision.

## Features

- AI-powered resume verification
- Resume credibility scoring
- Job description matching
- Candidate & Recruiter authentication
- Role-based dashboards
- Resume upload & analysis
- GitHub repository verification
- Certification verification
- Recruiter application management
- End-to-end hiring workflow

## Project Workflow

1. Candidate signs up and uploads their resume.
2. AI analyzes the resume.
3. Skills are verified against GitHub repositories and certifications.
4. Resume receives credibility and relevance scores.
5. Recruiters view verified candidate profiles.
6. Applications are managed through a centralized dashboard.
